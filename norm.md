                 4. По реализации:
BinaryTree состоит из корня Node и количества узлов. Для понимания Node<T> содердит значение типа T и указатели на левого и правого потомка и только один параметрический конструктор.
по методам BinaryTree:
в привате вспомогательные методы не нужные пользователю по жизни, все статик для удобства работы с поддеревом по указателю(а не всем объектом):
void destroy(Node<T>* n) -----удаляем рекурсивно поддерево начиная с узла n, обещаем что потом с size все будет хорошо
void visitImpl(Node<T>* n, Traversal, F&);  ------обойти в заданном порядке поддерево, применяя f   (на каком-то крутом гите было для удобного принта и разбиения на 2 вектора, например f-лямбда функция с cout)
Node<U>* mapImpl(Node<T>* n, F&); ----строим новое(не удаляя старое поддерево) поддерево, действуя на узел f
Node<T>* whereImpl(Node<T>* n, pred);   ----новое поддерево из поддерева на n, удовлетворяющее булевому условию pred
Acc reduceImpl(Node<T>* n, Traversal, Acc, F&); ---- вернуть значение Асс(свернуть дерево в него) обходя в заданном порядке, применяя f
void collect(Node<T>* n, Traversal, vector<T>&);  ----обойти, как задано, поддерево и сложить его значение value в вектор out
void collectPtrs(Node<T>* n, Traversal, vector<Node<T>*>&); --- обойти, как задано, но сложить ptr на узлы, допустим если захотим пройтись по узлам как по объектам
Node<T>* clone(Node<T>* n); ----- глубокое копирование поддерева(без указателей на одно и то же место)
bool subtreeEquals(Node<T>* a, Node<T>* b);  ------ для сравнения двух поддеревьев, ну и ответ да или нет

1. Идея: основываясь на принципаз ООП реализовать структуру бинарное дерево для: хранения элементов, различные преобразования хранимых данных, именение связей

2.1. Сущности:

Узел (Node) ----Элемент дерева, хранящий значение типа T и указатели на левого и правого потомков. Является строительным блоком структуры.
Бинарное дерево (BinaryTree) ----Иерархическая структура, состоящая из узлов, с выделенным корнем. Хранит количество элементов.
Обход (Traversal)   -----Упорядоченная последовательность посещения узлов: 6 вариантов перестановки ?Корень ? Левое ? Правое? (KLP, KPL, LPK, LKP, PLK, PKL).
Путь (Path)  -------Строка из символов L/R, задающая маршрут от корня к узлу.
Поддерево (Subtree)   -------Часть дерева, корнем которой является произвольный узел исходного дерева.
Исключение (Exception)  -------Сигнал об ошибке: пустое дерево, элемент не найден, неверный путь, неверный формат данных.
